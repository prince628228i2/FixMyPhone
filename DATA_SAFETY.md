# Data Safety mapping — pre-submission draft

| Data | Purpose | Shared? | Notes |
|---|---|---|---|
| Accessibility UI text/metadata | App functionality / requested automation | Potentially with configured AI provider | Only task-required context should be sent |
| Voice input | App functionality | Depends on Android speech provider | Captured only while listening |
| Contacts | App functionality | No by default | Used for contact resolution |
| Phone/call info | App functionality | No by default | Used for calling and call state |
| AI API key | App functionality | Sent to configured AI provider as authentication | Stored encrypted on device |

Verify every answer against the final implementation and Play Console questionnaire before publishing.
